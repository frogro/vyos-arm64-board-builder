# Main/test build completeness audit, 2026-09-27

Compared published main 9ec8edb with the current A–D+F test branch. The failed
run 36333055879 omitted libxtables-dev in the additional native kernel job;
47951b8 fixes it and preflights the header. Run 36335262291 is building that fix.

## Dependency coverage

The 31 packages from main's board candidate workflow have been moved unchanged
into tools/ci/board-build-packages.txt. Both workflow definitions in this TEST
branch now consume that same list. The optional kernel job additionally installs
dwarves, cpio and git. A set comparison against main's original list and shell
syntax checks passed. This consolidation does not alter published main and is
committed with CI skipped to avoid restarting the already corrected kernel run.
The image job uses the pinned, previously successful CLI and assembly containers;
its host package list is therefore not the same as the native kernel job's list.

## Component comparison

- A–D profiles, ordinary board workflow behavior and OOT module builder: no
  functional removal relative to main. The frozen A–D base is successful run
  36267716867, based on the same tree as main's D integration a03e55c. The final
  9ec8edb main commit adds D test documentation only.
- CLI: rebuilt from pinned upstream with current C/D/F sources. Includes earlier
  operator-runner, console-command, first-login initialization and ownership fixes.
- SD and ISO: use the existing assembly/update tooling with opt-in F extension;
  identical rootfs/kernel/DTB/initramfs checks remain. Profile identity is checked.
- Normal kernel: frozen corrected 6.18.50-vyos decoder payload, not overwritten
  by the optional Panthor build. Panthor has separately signed in-tree/OOT modules,
  its own initramfs and optional GRUB entry; normal saved default is not changed.
- Runtime: inspected the actual archived wayland-user-20260926 container locally,
  with no hardware devices or network. Chromium hash matches
  d1f979a39d0402060364e5a9202cb6e8772a7e3ec90c91622151defcb851eeb6.
  Xorg, seatd, PulseAudio/pactl, libnuma, libx264, libx265 and setcap are present.
  The kiosk launcher explicitly uses /usr/bin/weston 14.0.2 with the installed
  libweston-14 DRM and GL modules. /opt/weston16 is the separate headless test
  compositor; resolving 'weston' on PATH alone would check the wrong executable.
  The overlay now checks the physical-output backend paths explicitly.
- Sunshine: source build includes MPP-compatible-path, HEVC frame/EOS corrections,
  optional RGA conversion and opt-in KMS timing. Overlay carries updated audio and
  input helpers, MPP libraries and verified existing Chromium; no personal state.
- Device setup: capability-based playback/MPP mapping and read-only DT compatible
  mount are present. Existing configurations are intentionally not replaced.
- Update state: /config persistence and existing pairing/Tailscale identity are
  not regenerated by runtime packaging. Actual retention still needs update test.

## Validation and limits

95 F tests, 2 boot-menu tests and 72 relevant A–D/update/firstboot tests passed.
The image-name/remaining firstboot tests ran in the existing build container
because the desktop Python lacks tabulate; no test was weakened. Both changed
workflow install blocks pass bash syntax validation. All 31 baseline packages
are retained exactly; optional job extras are additional.

No additional missing component found in this audit. This does not prove the
unfinished native Sunshine build, full image assembly, new kernel boot or live
latency. The existing DRM-Wayland Sunshine CLI guard stays in place pending
performance acceptance; experimental RGA and timing are not enabled by default.
No new Vulkan path or Weston16 physical-output migration is claimed.
